🍽️ Okra Restaurant Website
Okra Restaurant is a modern and responsive restaurant website created as a learning project using HTML, CSS, and Bootstrap. The purpose of this project is to improve frontend web development skills and learn responsive website design.
🚀 Features


Responsive Navbar


Hero Section


Signature Dishes Cards


About Section


Gallery Page


Reservation Page


Footer with Social Links


Mobile Friendly Design


Bootstrap Components


Font Awesome Icons


🛠️ Technologies Used


HTML5


CSS3


Bootstrap 5


Font Awesome


📂 Pages Included


Home Page


Menu Page


About Page


Reservation Page


Gallery Page


📱 Responsive Design
The website is designed to be fully responsive for mobile, tablet, and desktop screens using the Bootstrap grid system.
🎯 Purpose of Project
This project was created for practice and learning purposes to:


Improve HTML structure skills


Practice CSS styling


Understand the Bootstrap framework


Learn how to create responsive layouts
